## 1. 产品意图

当前三步都是写死的 CSS Grid，整理页右侧「预览选中」窗口太小且无法放大。  
用户要像常见编辑器那样 **拖分割条改布局**，尤其在「编辑整理 → 整理」里能把右侧预览拉大。

---

## 2. 完成定义

1. **帧提取**：左预览 / 右参数之间可拖，两侧有最小宽度。
2. **编辑整理**：胶片条 / 右侧栏之间可拖；拉宽右侧后，「预览选中」画布明显变大（宽度跟栏走）。
3. **整理页**：预览区可 **竖向** 拖高（至少约 160px 到约 70vh），不只靠栏宽。
4. **导出**：左参数 / 右预览之间可拖。
5. 分割位置写入 `localStorage`，刷新后恢复。不写进 `project.json`。
6. 提取页拖完后裁剪框仍对准画面（调用现有 `layoutCrop()`）。
7. 双击分割条恢复该方向默认比例。

## 5. 实现要点

新建 `src/layout.ts`，在 `src/main.ts` 的 `boot()` 里调用 `initLayout()`（只加这一行调用，不要重排 boot）。

### 5.1 DOM

只插入分割条节点，不要改表单：

| 位置 | 节点建议 |
|---|---|
| `#panel-extract`：`.stage` 与 `.side` 之间 | `#split-extract` |
| `.edit-layout`：`.film-col` 与 `#edit-side` 之间 | `#split-edit` |
| `#panel-export`：`.side` 与 `.export-stage` 之间 | `#split-export` |
| `#side-organize .preview-box` 上方（竖向拉高预览） | `#split-organize-preview` |

用 `grid-template-columns` / `grid-template-rows` + CSS 变量，例如：

- `--extract-side: 360px`
- `--edit-side: 340px`
- `--export-side: 360px`
- `--organize-preview-h: 220px`

分割条宽度约 6–8px，可命中；`cursor: col-resize` / `row-resize`。不要用透明到完全看不见，给一条浅色缝即可。

若现有 grid 没有「中间一列给 splitter」，把 splitter 做成绝对定位在两栏交界、或改成 `auto 6px 1fr` 这类三列。改 grid 时 **不要删掉** `.stage` / `.side` / `.film-col` 的 id 和现有 class。

### 5.2 拖拽

- `pointerdown` 后 `setPointerCapture`，`pointermove` 改对应 CSS 变量，`pointerup` 写入 localStorage。
- 最小宽：预览区 / 胶片条 ≥ 280px，侧栏 ≥ 280px；整窗不能拖到一栏消失。
- 提取列宽变化时调用 `layoutCrop()`（可 rAF 节流，拖结束必须再调一次）。
- 整理预览：容器变了要更新 canvas 的 **显示尺寸**；backing store 建议按 `clientWidth × clientHeight`（可乘 `devicePixelRatio`）更新，保持画质。`drawPreviewFrame` 已按 canvas 宽高 contain 绘制，改尺寸后正在播放应仍正常。
- 不要改 `startPreview` 的选中集合 / fps 逻辑。

### 5.3 存储 key

```
vsp.layout.extractSide
vsp.layout.editSide
vsp.layout.exportSide
vsp.layout.organizePreviewH
```

非法值、NaN、超出窗口的值回退默认。  
双击对应 splitter：删除该 key 并恢复该方向默认像素/比例。

布局属于本机偏好，不要进 `Project` schema，不要 `persistNow`。

### 5.4 整理预览高度

完成门槛是：用户在整理 tab 里能把 `#organize-preview` 明显拉高、拉宽。

建议 `.preview-box` 用 flex 列布局，canvas `flex: 1` 且高度吃 `--organize-preview-h`。侧栏本身已 `overflow: auto`，预览变高后侧栏可滚动，胶片条仍在左侧可滚。

## 6. 验收

在浏览器里按真实用户路径过一遍：

1. 编辑整理 → 整理：把右侧栏拖到约半屏，「预览选中」明显变大；点预览仍循环播放选中帧。
2. 再把预览区竖向拉高，人物预览变大，胶片条仍可滚动。
3. 刷新页面，栏宽和预览高度还在。
4. 双击分割条，该方向回到默认。
5. 帧提取：拖窄/拖宽参数栏后，绿裁剪框仍贴在画面内容上，不要漂到黑边。
6. 导出页左右也能拖，预览画布还在。
7. 窗口缩得很窄时不能把一栏拖没。
